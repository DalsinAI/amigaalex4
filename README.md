# Alex the Allegator 4 for GFOS

The AmiCradle Team's port of Alex the Allegator 4 (Johan Peitz's
GameBoy-style platform game, in carstene1ns's SDL 2 version) to GFOS:
AmigaOS 3.2 with GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2.
It ships as a release archive with an Installer and as the GFOpenUp part
Parts/Alex4.

Upstream is fetched at build time (package/alex4.lock); this repository
holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
